LimeFlow

![LimeFlow](LimeFlow-GitHub-Banner.png)

<p align="center">
  Локальная обработка трафика на Android без root-прав.
</p>

## Возможности

- работа через стандартный Android `VpnService` без удалённого VPN-сервера;
- каталог из 26 встроенных стратегий;
- создание, изменение и удаление собственных стратегий;
- единая проверка профилей для YouTube, Discord, CDN и DNS;
- сохранение результатов и сортировка стратегий от лучших к худшим;
- раздельная маршрутизация: все приложения, только выбранные или исключения;
- быстрый переключатель Android и статистика трафика в уведомлении;
- светлая, тёмная и системная темы;
- динамическая палитра обоев на Android 12 и новее;
- расширенные параметры HTTP, HTTPS, TLS, UDP, SNI, TTL и OOB.

## Установка

1. Откройте раздел [Releases](../../releases).
2. Скачайте последний файл `LimeFlow-*.apk`.
3. Разрешите установку приложений из браузера или файлового менеджера.
4. При первом запуске подтвердите системный запрос на VPN-подключение.

LimeFlow не требует root-прав. Android показывает значок VPN, потому что приложение
использует локальный VPN-интерфейс для обработки трафика на самом устройстве.

## Как пользоваться

1. Откройте **Стратегии**.
2. Запустите общую проверку либо проверьте один профиль.
3. Выберите подходящую стратегию в отсортированном списке.
4. Вернитесь на главный экран и нажмите **Включить**.

Работа конкретной стратегии зависит от провайдера, типа сети и текущих правил
фильтрации. Результат проверки является рекомендацией, а не гарантией.

## Свои стратегии

На экране стратегий нажмите `+`, укажите название и параметры движка. Собственные
профили хранятся только на устройстве. Их можно изменять, удалять и проверять так
же, как встроенные.

## Фильтр приложений

В разделе **Настройки → Фильтр приложений** доступны три режима:

- обрабатывать трафик всех приложений;
- не обрабатывать выбранные приложения;
- обрабатывать только выбранные приложения.

Изменения применяются при следующем подключении LimeFlow.

## Конфиденциальность

LimeFlow не содержит аналитики, рекламы и собственного удалённого VPN-сервера.
Проверка стратегий выполняет сетевые запросы к проверяемым публичным доменам.
Подробности находятся в [PRIVACY.md](PRIVACY.md).

## Сборка

Потребуются:

- JDK 17;
- Android SDK 34;
- Android NDK 25.1.8937393;
- CMake 3.22.1.

Клонирование и сборка:

```bash
git clone --recurse-submodules https://github.com/Ramixy/LimeFlow.git
cd LimeFlow
./gradlew assembleDebug
```

Готовый APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

На Windows используйте `gradlew.bat assembleDebug`.
