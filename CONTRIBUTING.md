# Участие в разработке

Спасибо за интерес к LimeFlow.

## Сообщение об ошибке

Перед созданием Issue:

1. проверьте, что используется последняя версия;
2. повторите проблему в Wi‑Fi и мобильной сети, если это безопасно;
3. укажите модель устройства, версию Android и выбранную стратегию;
4. приложите журнал LimeFlow без личных данных.

Не публикуйте IP-адреса, токены, пароли и другие секреты.

## Изменения кода

1. Создайте отдельную ветку.
2. Сохраняйте существующие лицензионные уведомления.
3. Запустите:

   ```bash
   ./gradlew testDebugUnitTest lintDebug assembleDebug
   ```

4. Опишите поведение до и после изменения.

Изменения нативных компонентов должны сохранять соответствующие MIT-лицензии.
