# LimeFlow 1.1.1 + встроенный прокси-раздел

TG WS Proxy подключён к LimeFlow как отдельный Android library-модуль
`tgwsproxy`. Его `ProxyController`, `ProxyService`, хранилище настроек и
оригинальная нативная библиотека используются напрямую. Обёртка
`EmbeddedProxyFragment` только размещает исходный Compose-интерфейс внутри
отдельной вкладки LimeFlow.

Что добавлено в LimeFlow:

- нижние вкладки LimeFlow и «Прокси» с иконками фиксированного размера;
- переход из уведомления и настроек быстрой плитки в интегрированную вкладку;
- синяя палитра TG WS Proxy, совпадающая с дневной и ночной темой LimeFlow;
- исключение Telegram из VPN-фильтра при первой установке настроек;
- пошаговый конструктор пользовательских стратегий в настройках;
- второй метод цепочки, фильтры протоколов/портов/запросов, TCP Fast Open,
  fake offset/SNI, OOB-байт, TLS minor и таймаут в конструкторе;
- раздельные имена ресурсов, DataStore, уведомления и порты обоих движков.

Итоговый APK поддерживает `armeabi-v7a` и `arm64-v8a`: это пересечение
архитектур, для которых присутствуют оба нативных движка.

## Сборка

Требуются JDK 17, Android SDK 34, NDK 25.1.8937393 и CMake 3.22.1.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Нативные исходники TG WS Proxy 1.2.3 и его GPLv3-лицензия сохранены в
`tgwsproxy/upstream-native`. Приложение использует поставленные автором
библиотеки `libtgwsproxy.so` без изменения их поведения.
