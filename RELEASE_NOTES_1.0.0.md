# LimeFlow 1.0.0

Первый публичный выпуск LimeFlow.

## Возможности

- локальное подключение через Android VpnService без root;
- 26 встроенных стратегий для разных типов соединений;
- рекомендации отдельно для YouTube и Discord;
- проверка одной стратегии или всего каталога;
- сохранение и сортировка результатов проверки;
- собственные стратегии с редактированием и удалением;
- фильтр приложений с режимами включения и исключения;
- динамическая системная палитра Android 12+;
- быстрый переключатель и счётчик трафика в уведомлении;
- расширенные настройки сетевого движка.

## Установка

Скачайте `LimeFlow-1.0.0.apk` из файлов релиза и установите его на Android.
При первом включении подтвердите стандартный системный запрос VPN.

Работа стратегий зависит от провайдера и сети. LimeFlow не является удалённым
VPN, не скрывает IP-адрес и не гарантирует доступность конкретного сервиса.
