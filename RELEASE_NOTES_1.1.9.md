# LimeFlow 1.1.9

Движок UDP снова как в 1.1.7, поверх него — список сайтов, сортировка
стратегий и повседневные удобства.

## Основные изменения

- junk-поезд UDP без пакетов I1–I5, из-за которых ломались проверки;
- desync только для отмеченных доменов (список как у zapret, по умолчанию всё включено);
- сортировка стратегий по числу успешных проверок, закрепление и «Применить лучшую»;
- на главном экране имя стратегии и счёт;
- отдельная память стратегии для Wi‑Fi и мобильной сети;
- копирование команды стратегии;
- запрос не глушить VPN батареей;
- это локальный обход DPI, не шифрование Amnezia/WireGuard.
