# LimeFlow 1.5.0

## Новое

- GameFilter в Zapret Engine (root): включение для TCP и UDP по отдельности, настройка портов через списки и диапазоны. Чтобы исключить RTMP, введите TCP `1024-1934,1936-65535`.
- Результаты проверки стратегий разделены по Wi-Fi и мобильным операторам. Текущего оператора приложение определяет по системным данным Android; историю можно открыть в каталоге стратегий. Приложение проверяет только текущую подключённую сеть, не симулируя МТС, Билайн или МегаФон.
- Обновлены `list-google.txt` и `list-exclude.txt` из Flowseal 1.10.3.

## Исправления

- Исправлен разбор конфигов Flowseal: Windows-команды из `.bat` не передаются в `nfqws`.
- Главная кнопка показывает состояние подключения до подтверждения службы; экран Zapret Engine показывает запуск и остановку.
- Пользовательские списки больше не перезаписываются при старте Zapret Engine.
- Остановка root-движка завершает только его процесс и удаляет собственные правила iptables.
- Исправлена совместимость проверки процессов с Android 6 и публикация раздельных APK в CI.

Windows-исправления Flowseal для GitHub hosts, PowerShell-тестера и диагностики папки OneDrive не применяются к Android-приложению.

APK собраны как debug-варианты для arm64-v8a, armeabi-v7a и universal. Для обновления поверх установленного APK подпись должна совпадать; если Android сообщает о несовместимой подписи, перед переустановкой сохраните настройки.
